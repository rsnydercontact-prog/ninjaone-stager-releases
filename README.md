# NinjaOne Stager — releases

Download the latest `.dmg` from [Releases](../../releases/latest):

- `NinjaOne-Stager-<version>-arm64.dmg` — Apple Silicon Macs
- `NinjaOne-Stager-<version>-x64.dmg` — Intel Macs

Open the .dmg and drag NinjaOne Stager into Applications. The first time, right-click the app and choose Open.
If macOS says the app is damaged: `xattr -dr com.apple.quarantine "/Applications/NinjaOne Stager.app"`

The app needs an activation token for each Mac. Send the Activation ID it shows to Ryan Snyder.
Installed copies check this page for a newer version each time they open.
